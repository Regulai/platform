# Procedencia

SKILL.md, references/model.md y scripts/random_walk.py son código e instrucciones
originales de regulAI, incorporados en P1 el 16-10-2026 bajo la licencia BSL-1.1
del proyecto. La revisión y el SHA-256 de carpeta se calculan al instalar;
no se atribuye una revisión upstream publicada inexistente.

NumPy es una dependencia del runtime ya fijada en 2.5.3, no se redistribuye dentro
de este paquete. Conserva su licencia BSD y avisos en la imagen del runtime.
