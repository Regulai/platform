About Obfuscation

Obfuscation automatically masks sensitive data in user prompts before sending them to AI engines.

Local Mode detects:
  • Emails
  • Phone numbers
  • Credit cards, DNI/NIE, IBAN
  • API keys, AWS keys
  • IP addresses
How it works:
  • Scans text for sensitive patterns
  • Replaces with tokens like [EMAIL_1]
  • Creates alert when data is masked
